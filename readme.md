# ADsP 기출문제 풀이

데이터분석준전문가(ADsP) 기출문제를 풀어보는 페이지. https://adsp.aleph.kr

## 풀이 방식

- **무한 문제 풀이** — 전체 문항 중에서 한 문제씩 랜덤으로 나오고, 정답 확인하면 바로 다음 문제로 넘어감. 과목이나 회차를 골라서 풀 수도 있음.
- **모의고사** — 전체 회차에서 과목별로 무작위로 뽑은 50문항으로 실전처럼 풀어보는 모드.
- **회차별 풀이** — 원하는 회차 하나를 골라서 그 회차 문제를 그대로 풀어봄.
- **틀린 문제 모아보기** — 어떤 모드에서 틀렸든 오답만 따로 모아서 다시 볼 수 있음.

풀이 기록은 브라우저 IndexedDB에 저장되고 서버로는 보내지 않는다.
